# Dynamic React Dashboard

A responsive and interactive dashboard interface developed using React.js.

## Purpose

This project demonstrates React components, custom hooks, state management, responsive design and interactive user interface features.

## Features

- Dynamic dashboard
- Custom React hook
- State management
- Sales overview
- Time period filtering
- Dark and light mode
- Sidebar navigation
- Statistics cards
- Recent activity
- Responsive design

## Technologies

- React.js
- JavaScript
- CSS
- Vite
- Lucide React
